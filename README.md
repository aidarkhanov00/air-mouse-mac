# Air Mouse для MacBook

Локальное управление мышью через камеру. Используется одна рука — левая или правая.
Это Python-приложение с окном камеры, а не подписанный установщик .app.

## Установка
Нужен macOS 11+ и Python 3.11 (можно Python 3.10 или 3.12).
Зафиксированные библиотеки не рассчитаны на Python 3.13/3.14.
Сборки MediaPipe 0.10.21 доступны для Intel и Apple Silicon.
Python: https://www.python.org/downloads/macos/

Откройте Terminal, введите `cd `, перетащите распакованную папку air-mouse-mac
в Terminal и нажмите Enter. Затем:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python air_mouse.py
```

Если установлен Python 3.12, замените только первую команду на `python3.12 -m venv .venv`.
Последующие запуски из папки: `.venv/bin/python air_mouse.py`.
Ничего не устанавливайте через sudo. Существующий веб-проект не меняется.

## Разрешения macOS
Системные настройки → Конфиденциальность и безопасность:
- Камера: разрешите приложению, из которого запускаете программу (Terminal, VS Code или Python — смотрите имя в запросе).
- Универсальный доступ: разрешите этому же приложению управление компьютером.
После изменения разрешений полностью закройте и снова откройте приложение запуска.
На старых версиях macOS раздел находится в «Защита и безопасность → Конфиденциальность».
Без разрешения Универсального доступа включение управления блокируется.

## Управление
Программа начинает с ПАУЗЫ. Щёлкните по окну камеры и нажмите Space.
- Только указательный палец выпрямлен: курсор двигается. Большой держите отдельно от указательного.
- Перед кликом подержите этот жест хотя бы 0,35 секунды.
- Соедините большой и указательный на 0,1–0,5 секунды и разъедините: левый клик.
- Держите щипок более 0,5 секунды: зажим кнопки. Двигайте рукой, разъедините пальцы для отпускания.
- Указательный и средний подняты, остальные согнуты: двигайте руку вертикально для прокрутки.
- Кулак, открытая ладонь или исчезновение руки: движение останавливается, зажатая кнопка отпускается.
  Это временная остановка: указательный палец снова возобновляет движение.
- Space в активном окне камеры: постоянная пауза / продолжение.
- Esc или Q в активном окне камеры: выход. Это НЕ глобальные горячие клавиши.
- Ctrl+C в Terminal: выход.
- Аварийная остановка: трекпадом переведите курсор в угол основного экрана.
  Автоматическое движение оставляет отступ от углов, чтобы случайно не сработала остановка.

Рамка в кадре обозначает область движения: указательный палец проходит её,
а курсор — весь основной экран. Работает с основным монитором; несколько экранов не поддерживаются.
Короткий щипок удерживает курсор на месте, чтобы клик не смещался.

## Диагностика
- Проверка камеры без управления: `python air_mouse.py --preview`.
- Другая камера: `python air_mouse.py --camera 1`.
- Обратная прокрутка: `python air_mouse.py --reverse-scroll`.
- Нет изображения: проверьте доступ к камере; закройте приложения, занявшие её.
- Курсор не двигается: проверьте Универсальный доступ, перезапустите Terminal и нажмите Space в окне камеры.
- Ошибка No matching distribution: проверьте `python --version`; используйте 3.11 или 3.12, пересоздав .venv.
- Ошибка сертификатов после установки Python с python.org: запустите Install Certificates.command
  в папке Applications/Python 3.11 (либо вашей версии). Не отключайте проверку TLS.

Модель скачивается при первом запуске. Для загрузки нужен интернет; после этого
распознавание работает локально. Видео не записывается и никуда не отправляется.
При необходимости скачайте модель вручную рядом с air_mouse.py под именем hand_landmarker.task:
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

Порог щипка и сглаживание можно настроить в controller.py.
Распознавание эвристическое: держите ладонь к камере, обеспечьте хорошее освещение.
Проверены синтаксис и переходы состояний на искусственных входах. Реальная камера,
точность жестов, разрешения macOS и события мыши требуют проверки на вашем Mac.

Источники API:
